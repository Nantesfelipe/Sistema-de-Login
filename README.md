SystemLogin

Sistema de Login simples desenvolvido para praticar conceitos de Front-End e lógica de programação utilizando JavaScript e localStorage.

📌 Sobre o Projeto

O SystemLogin foi meu primeiro projeto utilizando JavaScript para criar um fluxo real de autenticação no Front-End.
O objetivo principal foi praticar:

Manipulação do DOM
Eventos em JavaScript
Estruturas condicionais
Armazenamento de dados com localStorage
Organização de código
Fluxo de login e cadastro de usuários

O sistema permite que usuários realizem cadastro e login utilizando informações armazenadas localmente no navegador.

🚀 Funcionalidades
✅ Cadastro de usuário
✅ Login de usuário
✅ Validação de campos
✅ Armazenamento de dados no localStorage
✅ Verificação de autenticação
✅ Interface simples e responsiva

🛠️ Tecnologias Utilizadas
HTML5
CSS3
JavaScript
